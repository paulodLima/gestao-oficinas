# PRD — Acesso seguro do cliente

Cliente acessa o acompanhamento pelo contexto da oficina e placa, validando um código único enviado ao contato verificado. Alternativamente, a oficina pode emitir link aleatório exclusivo e revogável de uma OS.

Regras: nenhuma consulta revela se placa, cliente ou OS existem; CPF não é senha; código expira, tem tentativas limitadas e uso único; link é somente leitura e não aprova adicionais; autorização de veículo/OS é revalidada a cada leitura.
